# Fonts embedded in the report

The report embeds these fonts (Latin subset, variable weight) so it renders the same offline.
Inter and JetBrains Mono are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).

| Font | Copyright |
| --- | --- |
| Inter | The Inter Project Authors (https://github.com/rsms/inter) |
| JetBrains Mono | The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) |

Files come from the Fontsource packages `@fontsource-variable/inter` and
`@fontsource-variable/jetbrains-mono`.

`nippo-*.woff2` are subsets of Nippo by the Indian Type Foundry (Fontshare, ITF Free Font License),
the same subsets the fa1c0n profile artwork embeds: printable ASCII and `· – — ’ …`. Inter covers
any other glyph.
