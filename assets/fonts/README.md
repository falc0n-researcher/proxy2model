# Fonts

`nippo-*.woff2` are subsets of **Nippo** by the Indian Type Foundry (distributed through Fontshare
under the ITF Free Font License), the same subsets the fa1c0n profile artwork embeds. They hold
printable ASCII plus `· – — ’ …`, so keep the artwork's text to those characters.

`scripts/build_readme_svgs.py` inlines them into `assets/readme/*.svg`; the docs site serves a copy
from `docs/assets/fonts/`.
